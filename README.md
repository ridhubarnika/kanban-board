# Kanban Board Project

## 📌 Description
This is a simple Kanban board built using HTML, CSS, and JavaScript.  
It allows users to create tasks and move them between different stages.

## 🚀 Features
- Add new tasks
- Move tasks by clicking
- 3 workflow columns: To Do, In Progress, Done

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## ▶️ How to Run
1. Download or clone the repository
2. Open `index.html` in any browser
3. Add tasks and click to move them

## 🔄 Workflow
To Do → In Progress → Done → Back to To Do
